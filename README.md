# my-tools

A collection of personal utilities and tools, primarily built with Claude.

## Tools

### display-utils

macOS utilities for workspace and display management:

- **rearrange_windows.py** - Automatically arrange application windows across multiple monitors with configurable layouts
- **change_display_settings.py** - Configure display resolution, refresh rate, and HiDPI modes using the Quartz framework

See [display-utils/README.md](display-utils/README.md) for detailed documentation.
